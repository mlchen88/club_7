# Google Apps Script 後端設定說明

## 重要：請更新你的 Apps Script 程式碼

請將以下完整的程式碼**替換**你現有的 `Code.gs`：

```javascript
const SHEET_NAME = '工作表1'; // 如果你的頁籤不是「工作表1」，請改成實際名稱
const ADMIN_PASSWORD = 'admin2025'; // 管理員密碼（請自行修改）

function doGet(e) {
  const action = (e.parameter.action || '').trim();
  const password = (e.parameter.password || '').trim();
  
  // 測試連線（需管理員密碼）
  if (action === 'test') {
    if (password !== ADMIN_PASSWORD) {
      return outputJSON({ ok: false, error: '管理員密碼錯誤' }, 401);
    }
    return outputJSON({ ok: true, message: '後端連線正常' });
  }
  
  // 讀取所有提交資料（需管理員密碼）
  if (action === 'list') {
    if (password !== ADMIN_PASSWORD) {
      return outputJSON({ ok: false, error: '管理員密碼錯誤' }, 401);
    }
    
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_NAME);
    if (!sheet) {
      return outputJSON({ ok: false, error: '找不到工作表：' + SHEET_NAME }, 404);
    }
    
    const values = sheet.getDataRange().getValues();
    if (values.length < 2) return outputJSON([]);
    
    const header = values[0];
    const rows = values.slice(1);
    
    // 期望表頭：班級, 座號, 姓名, 學號, 填寫時間, 志願1..志願15
    const result = rows
      .filter(r => r.join('').trim() !== '')
      .map(r => {
        const obj = {
          class: String(r[0] || ''),
          seat: String(r[1] || ''),
          name: String(r[2] || ''),
          id: String(r[3] || ''),
          submitTime: String(r[4] || ''),
          clubs: []
        };
        // 志願欄位（第5欄開始到第19欄）
        for (let i = 5; i < Math.min(5 + 15, r.length); i++) {
          if (r[i] && String(r[i]).trim()) {
            obj.clubs.push(String(r[i]).trim());
          }
        }
        return obj;
      });
    
    return outputJSON(result);
  }
  
  return outputJSON({ ok: true, message: 'Use ?action=list&password=YOUR_PASSWORD to fetch data' });
}

function doPost(e) {
  try {
    const body = JSON.parse(e.postData.contents);
    const action = (body.action || '').trim();
    
    // 提交學生資料（不需密碼，但可選擇性加入驗證）
    if (action === 'submit') {
      const p = body.payload || {};
      
      // 驗證必填欄位
      if (!p.class || !p.seat || !p.name || !p.id) {
        return outputJSON({ ok: false, error: '缺少必填欄位' }, 400);
      }
      
      // 驗證志願數量
      const clubs = Array.isArray(p.clubs) ? p.clubs.filter(c => c && String(c).trim()) : [];
      if (clubs.length < 8) {
        return outputJSON({ ok: false, error: '至少需要填寫 8 個志願' }, 400);
      }
      if (clubs.length > 15) {
        return outputJSON({ ok: false, error: '最多只能填寫 15 個志願' }, 400);
      }
      
      const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_NAME);
      if (!sheet) {
        return outputJSON({ ok: false, error: '找不到工作表：' + SHEET_NAME }, 404);
      }
      
      // 檢查是否已存在相同學號的記錄（避免重複提交）
      const existingData = sheet.getDataRange().getValues();
      const existingIds = existingData.slice(1).map(r => String(r[3] || '').trim());
      if (existingIds.includes(String(p.id).trim())) {
        return outputJSON({ ok: false, error: '此學號已提交過，無法重複提交' }, 400);
      }
      
      // 建立資料列
      const row = [
        String(p.class || ''),
        String(p.seat || ''),
        String(p.name || ''),
        String(p.id || ''),
        p.submitTime || new Date().toLocaleString('zh-TW'),
      ];
      
      // 補齊志願欄位至15個
      for (let i = 0; i < 15; i++) {
        row.push(clubs[i] || '');
      }
      
      sheet.appendRow(row);
      return outputJSON({ ok: true, message: '提交成功' });
    }
    
    return outputJSON({ ok: false, error: 'Unknown action' }, 400);
  } catch (err) {
    return outputJSON({ ok: false, error: String(err) }, 500);
  }
}

function outputJSON(obj, code) {
  const out = ContentService.createTextOutput(JSON.stringify(obj));
  out.setMimeType(ContentService.MimeType.JSON);
  return out;
}

// 初始化工作表（首次執行時建立表頭）
function initializeSheet() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = ss.getSheetByName(SHEET_NAME);
  
  if (!sheet) {
    sheet = ss.insertSheet(SHEET_NAME);
  }
  
  // 如果沒有資料，建立表頭
  if (sheet.getLastRow() === 0) {
    const header = ['班級', '座號', '姓名', '學號', '填寫時間'];
    for (let i = 1; i <= 15; i++) {
      header.push('志願' + i);
    }
    sheet.appendRow(header);
    
    // 設定表頭樣式
    const headerRange = sheet.getRange(1, 1, 1, header.length);
    headerRange.setFontWeight('bold');
    headerRange.setBackground('#4285f4');
    headerRange.setFontColor('#ffffff');
  }
}
```

## 設定步驟

1. **修改管理員密碼**（第2行）：
   ```javascript
   const ADMIN_PASSWORD = 'admin2025'; // 改為你想要的密碼
   ```

2. **確認工作表名稱**（第1行）：
   ```javascript
   const SHEET_NAME = '工作表1'; // 改成你的實際工作表名稱
   ```

3. **初始化工作表**（首次設定時執行一次）：
   - 在 Apps Script 編輯器中，選擇 `initializeSheet` 函數
   - 點擊「執行」按鈕
   - 這會自動建立表頭列

4. **重新部署**：
   - 檔案 → 部署 → 管理部署
   - 點擊「編輯」圖示
   - 選擇「新增版本」
   - 儲存後會自動更新

## 功能說明

- **測試連線** (`?action=test&password=YOUR_PASSWORD`)：驗證後端是否正常運作
- **讀取資料** (`?action=list&password=YOUR_PASSWORD`)：需要管理員密碼
- **提交資料** (`POST /` 含 `action=submit`)：學生提交，會檢查重複學號

## 安全注意事項

⚠️ **重要**：前端的管理員密碼必須與後端一致，否則管理員功能無法使用。

建議：
- 定期更換密碼
- 不要在公開場合洩露密碼
- 考慮使用更複雜的密碼
